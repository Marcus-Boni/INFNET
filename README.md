## 🎯 Tipos de Atividades

### 📝 TP - Teste de Performance

- **Descrição:** Trabalhos práticos progressivos que desenvolvem competências específicas da disciplina
- **Quantidade:** 3 TPs (disciplinas regulares) ou 5 TPs (projeto de bloco)
- **Objetivo:** Aplicação prática dos conceitos aprendidos

### 📊 AT - Assessment

- **Descrição:** Avaliação final integradora da disciplina
- **Quantidade:** 1 por disciplina/projeto
- **Objetivo:** Demonstrar domínio completo dos conteúdos abordados

## 📄 Como Acessar as Atividades

### Passo a Passo:

1. **Escolha a disciplina** que deseja avaliar
2. **Navegue até a pasta** correspondente (ex: `25E4_1/`)
3. **Entre na atividade** específica (ex: `TP1/`, `TP2/`, `AT/`)
4. **Leia o README.md** dentro da pasta da atividade para instruções detalhadas

### Exemplo Prático:

```bash
# Para acessar o TP1 de Engenharia de Testes de Software:
25E4_1/TP1/

# Para acessar o AT do Projeto de Bloco:
25E4_5/AT/
```
